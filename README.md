# 🧮 JavaScript Calculator - The Odin Project

Proyecto de calculadora interactiva desarrollado como parte del plan de estudios de [The Odin Project](https://www.theodinproject.com/). Una aplicación web funcional construida desde cero para realizar operaciones aritméticas básicas con una interfaz limpia y responsive.

## 🚀 Enlaces
- **🔗 Vista en vivo (Live Demo):** [Prueba la calculadora aquí](https://dannyea1385-tech.github.io/calculator/) *(o pega tu enlace final de GitHub Pages)*
- **📂 Repositorio:** [github.com/dannyea1385-tech/calculator](https://github.com/dannyea1385-tech/calculator)

## 🛠️ Tecnologías y Herramientas
* **HTML5:** Estructura semántica de la interfaz de la calculadora.
* **CSS3:** Diseño, estilos personalizados y distribución visual.
* **JavaScript (ES6+):** Lógica de cálculo, manejo de eventos del DOM y almacenamiento temporal de entradas.
* **Git & GitHub:** Control de versiones y despliegue web mediante GitHub Pages.

## ✨ Características principales
* Operaciones aritméticas básicas: Suma, resta, multiplicación y división.
* Manejo de decimales y botón de borrado (backspace) para corregir entradas.
* Prevención de errores comunes (como división entre cero).
* Interfaz intuitiva y adaptada para diferentes tamaños de pantalla.
